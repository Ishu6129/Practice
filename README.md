# Practice Repository

This repository contains practical examples for building LLM applications with LangChain, LangGraph, and LangSmith.

## What is inside

- [langchain/](langchain/) - notebooks and Python examples for prompts, chains, document loaders, embeddings, retrievers, vector stores, structured output, text splitting, tools, and chat-style apps.
- [langGraph/](langGraph/) - workflow examples for chatbots, memory, conditional branches, iterative flows, parallel tasks, subgraphs, and persistence.
- [langsmith/](langsmith/) - scripts and examples for tracing, debugging, and monitoring LLM applications.

## Notes

- Many examples require API keys and environment variables.
- Some notebooks need dependencies from the requirements file in [langchain/](langchain/).
