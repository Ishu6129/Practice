# LangSmith Examples

This folder contains examples for tracing and monitoring LangChain and LangGraph runs.

## What is inside

- [1_simple_llm_call.py](1_simple_llm_call.py) - a basic single-call tracing example.
- [2_sequential_chain.py](2_sequential_chain.py) - tracing a sequential chain run.
- [3_rag_basic_trace.py](3_rag_basic_trace.py) - basic tracing for a RAG flow.
- [4_rag_functional_trace.py](4_rag_functional_trace.py) - tracing a functional RAG pipeline.
- [5_rag_trace_index.py](5_rag_trace_index.py) - tracing an indexed retrieval flow.
- [6_rag_trace_to-all.py](6_rag_trace_to-all.py) - tracing multiple steps together.
- [7_agent.py](7_agent.py) - tracing an agent example.
- [8_langgraph.py](8_langgraph.py) - tracing a LangGraph workflow.

## Notes

- These examples are intended for learning how LangSmith captures prompts, traces, and run metadata.
- Some scripts may need environment variables and API keys configured before they run.
