# LangGraph Examples

This repository contains workflow examples built with LangGraph for chatbots, stateful agents, and multi-step reasoning flows.

## Overview

LangGraph is used here to demonstrate common workflow patterns:
- chatbots and conversational flows
- conditional branching
- iterative workflows
- memory and state handling
- parallel execution
- sequential processing
- subgraphs and nested workflows

## Repository layout

- `CX_ChatBots/` - chatbot examples with different interaction patterns
- `CX_ConditionalWorkflow/` - workflows that branch based on conditions
- `CX_IterWorkflow/` - iterative and repeated workflow patterns
- `CX_Memory/` - memory-based examples for state handling
- `CX_ParallelWorkflow/` - parallel workflow examples
- `CX_SeqWorkflow/` - sequential workflow examples
- `CX_Subgraph/` - examples using subgraphs and nested workflows
- `test.ipynb` - notebook for trying out LangGraph ideas

## Getting started

1. Open this folder in VS Code.
2. Install any required Python packages or runtime dependencies for LangGraph.
3. Run the example scripts or notebook for the workflow pattern you want to explore.
