# LangGraph Examples

This folder contains workflow examples built with LangGraph for chatbots, stateful agents, and multi-step reasoning flows.

## What is inside

- [CX_ChatBots/](CX_ChatBots/) - chatbot examples with different interaction patterns.
- [CX_ConditionalWorkflow/](CX_ConditionalWorkflow/) - workflows that branch based on conditions.
- [CX_IterWorkflow/](CX_IterWorkflow/) - iterative and repeated workflow patterns.
- [CX_Memory/](CX_Memory/) - memory-based examples for state handling.
- [CX_ParallelWorkflow/](CX_ParallelWorkflow/) - parallel workflow examples.
- [CX_SeqWorkflow/](CX_SeqWorkflow/) - sequential workflow examples.
- [CX_Subgraph/](CX_Subgraph/) - examples using subgraphs and nested workflows.
- [test.ipynb](test.ipynb) - a notebook for trying out LangGraph ideas.

## Notes

- These examples are meant for learning LangGraph concepts and workflow composition.
- Some notebooks may require additional packages and environment variables.
